## Week Overview

Week 6 is **Phase 3 --- Applied Project Work, Sprint 1**.

The focus of the week is **project planning, core routes, and database
schema**. The sprint follows the standard Phase 3 workflow: Sprint
Planning on Day 1, daily stand-ups, mentor code review, Sprint Review,
and Sprint Retrospective.

### Week Goals

-   Run a complete Sprint Planning session and create a realistic
    backlog.
-   Design and document the project's complete database schema.
-   Implement the EF Core data model using Fluent API and code-first
    migrations.
-   Build paginated, filterable, sortable catalog/read endpoints
    projecting to DTOs.
-   Implement write operations with business logic and database
    transactions where needed.
-   Open a clean pull request and participate in mentor code review.
