# Week 3 – ASP.NET Core Web API Fundamentals

## Overview

During Week 3 of the BinX Backend .NET Internship, I built a RESTful ASP.NET Core Web API using Entity Framework Core and SQL Server. The week focused on designing a database, implementing CRUD operations, applying DTOs and the Service Layer pattern, and testing/documenting the API using Postman.

---

## Learning Objectives

- Design a relational database using ERD.
- Build RESTful APIs with ASP.NET Core.
- Use Entity Framework Core with SQL Server.
- Implement CRUD operations.
- Apply DTOs to separate API contracts from data models.
- Organize business logic using the Service Layer pattern.
- Test APIs with Postman.
- Document APIs professionally.

---

## Week Breakdown

### Day 1 – REST API Design

- Designed RESTful API endpoints.
- Planned CRUD operations.
- Selected appropriate HTTP methods.
- Documented endpoint behavior and status codes.

---

### Day 2 – Database Design

- Designed the database schema.
- Created an Entity Relationship Diagram (ERD).
- Defined relationships between entities.
- Planned database normalization.

---

### Day 3 – Entity Framework Core

- Configured Entity Framework Core.
- Connected the project to SQL Server.
- Created models and DbContext.
- Generated and applied migrations.
- Seeded initial database data.

---

### Day 4 – CRUD API Development

Implemented complete CRUD operations for the **Book** resource:

- GET All Books
- GET Book by ID
- POST Create Book
- PUT Update Book
- DELETE Book

Additional improvements:

- DTO implementation
- Service Layer architecture
- Dependency Injection
- Proper HTTP status codes
- Error handling

---

### Day 5 – API Testing & Documentation

Completed API testing using Postman.

Implemented:

- Organized Postman Collection
- Happy Path testing
- Error Path testing
- Postman Environment using `{{baseUrl}}`
- Automated Postman Test Scripts
- Professional API Documentation (PDF)
