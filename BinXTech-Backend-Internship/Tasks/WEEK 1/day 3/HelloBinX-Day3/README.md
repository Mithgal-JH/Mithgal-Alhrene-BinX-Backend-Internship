# HelloBinX - Day 3

## 📌 Overview
This project was created as part of the BinX Backend .NET Internship - Week 1 (Day 3).

The goal of this task was to practice Object-Oriented Programming (OOP) concepts in C# by building a simple Store Management System.

---

## 🚀 Concepts Practiced

- Classes & Objects
- Constructors
- Inheritance
- Encapsulation
- Arrays
- Object Composition
- Basic User Input
- Calculating Order Total

---

## 🏗️ Project Structure

### Person
Represents a generic person with:
- Name
- Email

### Customer
Inherits from `Person` and can:
- Create a new order
- Select products from the store

### Product
Represents a product with:
- Name
- Price

### Order
Represents a customer order containing:
- Customer
- Selected Products
- Total Price

### Store
Contains:
- Available Products
- Orders
- Product Display Method

---

## ⚙️ Features

- Display available products
- Select multiple products
- Create a customer order
- Calculate the total order price
- Print order information

---

## 🛠️ Technologies

- C#
- .NET Console Application
- Object-Oriented Programming (OOP)
