## 📁 Projects

### Cardiac Patient Monitoring System

A backend REST API for managing patients, doctors, medications, appointments, patient medications, and vital signs in a cardiac patient monitoring system.

**Main technologies:**

- C#
- ASP.NET Core Web API
- .NET 10
- Entity Framework Core
- PostgreSQL
- ASP.NET Core Identity
- JWT Authentication
- FluentValidation
- Postman

The project also includes role-based authorization, API security features, database migrations, and API documentation.
